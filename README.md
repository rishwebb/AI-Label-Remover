# TRACELESS

## Overview

TRACELESS is a client-side web utility engineered for image metadata analysis, privacy redaction, and provenance sanitization. The application operates entirely within the user's web browser, executing binary-level inspections and selective segment stripping without transmitting files to external infrastructure.

The software addresses automated labeling mechanisms deployed by content distribution networks and social media platforms. Specifically, it identifies and isolates C2PA (Coalition for Content Provenance and Authenticity) manifest containers, IPTC generative markers, and personal exchangeable image file format (EXIF) data.

---

## Technical Mechanism

When synthetic media is generated by machine learning systems, origin assertions and parameter records are typically injected into specific application segments of the container file:

1. **C2PA Manifest Stores (APP11 Marker):**
   In JPEG containers, C2PA claims reside within standard ISO/IEC 19566-5 JUMBF structures located in segment marker 0xFFEB (APP11). In PNG containers, corresponding data is stored within caPX chunks. Automated ingestion pipelines parse these structures to flag content as algorithmically produced.

2. **IPTC and Extensible Metadata (XMP):**
   Generative properties are declared via fields such as DigitalSourceType set to trainedAlgorithmicMedia, along with software identifiers, prompt text, and seed values.

3. **Lossless Binary Slicing:**
   Conventional stripping techniques decode and re-encode pixel arrays through canvas elements, introducing compression generation loss. TRACELESS performs discrete binary pointer parsing, excising targeted APP11 and XMP headers while leaving entropy-coded image scans (DQT, DHT, SOS) bit-for-bit intact.

---

## Capabilities

- **Selective Binary Slicing:** Excises designated provenance markers while maintaining visual pixel parity.
- **Privacy Hardening:** Eliminates geographical coordinates (GPS), hardware serial identifiers, author data, and creation timestamps.
- **Structural Segment Analysis:** Visual breakdown of all APP markers, chunks, and metadata containers.
- **Verification and Checksumming:** Calculates pre- and post-processing cryptographic hashes (SHA-256) alongside byte reduction ratios.
- **Batch Processing:** Concurrently inspects and cleans multi-image queues with compressed ZIP archive export.
- **Zero Network Transmission:** All operations are contained within local TypedArray buffers (Uint8Array) inside the client session.

## Installation and Local Setup

Ensure Node.js (version 18 or higher) is available.

1. Clone the repository:
   ```bash
   git clone https://github.com/rishwebb/AI-Lebel-Remover.git
   cd AI-Lebel-Remover
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch local development server:
   ```bash
   npm run dev
   ```

4. Compile production distribution:
   ```bash
   npm run build
   ```

---

## Deployment

The application compiles into static HTML, JavaScript, and CSS assets inside the `dist` directory. It can be hosted on any static hosting environment, such as Cloudflare Pages, GitHub Pages, or Vercel.
